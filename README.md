# Lockbox
### Simple and Secure Password Storage
---
## About
Lockbox is a password storage program made with C++ and Qt using hashing and encryption to store unreadable data. 
It was born from my need of a seperate, secure, application-based password manager to improve my online security.
Also has a password generator to create secure passwords to ensure account safety online.

### Built With
* C++
* Qt
* CMake
* libsodium
